# Grii Slide Maker

It is a tool to create slides for service every week for GRII Hamburg church. 
It uses primarily pptx python library to create slides.
The songs are downloaded from google drive locally, and then added to the slides as images.
The static images are stored in the master slide template. 
The bible quotes are taken from Bible API call.
